# AI Compliance Evidence Collector
**MBA ZG583 — Management of AI Products — Capstone Assignment**
Student: Bhandare Kiran Arun Madhuri | Roll No: 2024BC26620

## Problem
IT infrastructure and security teams manually gather audit evidence (patch logs, access
controls, backup records, configuration baselines) across disconnected systems to satisfy
compliance audits (ISO 27001, SOC 2, internal governance reviews). This process is slow,
inconsistent across reviewers, and a common source of audit findings.

## Product Concept
An AI-powered copilot that maps required audit controls to existing evidence, automatically
flags gaps, and drafts evidence summaries for auditors — reducing manual evidence-chasing
during audit cycles.
